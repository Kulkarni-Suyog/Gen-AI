# GSTSaral

## Project Overview
GSTSaral is a beginner-friendly GST assistance application designed to help small business owners and taxpayers understand basic GST-related information.

## Product
GSTSaral - A Simple GST Assistance Application.

## Target Users
- Small business owners
- Shopkeepers
- GST taxpayers
- Beginners learning about GST

## Problem Statement
Many small business owners and beginners find GST rules, tax calculations, and GST-related procedures difficult to understand. They need a simple platform that provides basic GST information and helps them understand common GST questions.

## Objectives
- Provide basic GST-related information.
- Answer common GST questions.
- Demonstrate simple GST rules using Python.
- Make GST concepts easier to understand.

## Data Source
- Official GST Portal: https://www.gst.gov.in/
- GST-related educational information.
- Sample GST questions created for learning purposes.

## Technologies Used
- Python
- Git and GitHub
- Markdown

## Day 1 Deliverables
- Project introduction
- Interactive user input
- Menu-driven application
- Basic GST rule checking
