# GSTSaral – Generative AI GST Assistant

## 1. Product
GSTSaral is a Generative AI-based assistant that explains GST rules, rates, and regulations in simple language.

## 2. Target User
Small shopkeepers, kirana store owners, stationery shop owners, and small traders.

## 3. Problem Statement
Small business owners often find GST rules, tax rates, and government notifications difficult to understand.

## 4. Solution
GSTSaral provides simple answers to GST-related questions using official information.

## 5. Data Sources
- Official GST Council FAQs
- Official GST Council Press Releases
- Government GST notifications

## 6. Technologies
- Python
- Generative AI
- Git
- GitHub

## 7. Sample Questions
1. What is GST?
2. What is the Composition Scheme?
3. How do I calculate GST?
4. What is the GST rate for my product?

## 8. Project Goal
To make GST information easier to understand for small business owners.
